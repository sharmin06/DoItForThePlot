## 📌 About The Project
DoItForThePlot is a Semester 4 group project developed as an Event Management Web Application. The aim of this project is to provide a platform where users can explore events and access event-related features, while organizers can manage events through a dedicated dashboard.

The project focuses on creating an interactive and user-friendly interface with separate experiences for users and organizers.

# ⚙️ Running the Project Locally

## Prerequisites

Make sure you have:

- A modern web browser
- Node.js installed
- MySQL installed
- Local server environment

## Steps

1. Clone the repository:

```bash
git clone https://github.com/sharmin06/DoItForThePlot.git
```

2. Navigate to the project folder:

```bash
cd DoItForThePlot
```

3. Configure the required database settings.

4. Start the backend/server environment.

5. Open the application in your browser.
